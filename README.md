## 🎯 Dashboards
### 1. Summary Dashboard
**Key Performance Indicators (KPIs):**
- Total Loan Applications (MTD & MoM tracking)
- Total Funded Amount (MTD & MoM analysis)
- Total Amount Received (MTD & MoM changes)
- Average Interest Rate (MTD & MoM variations)
- Average Debt-to-Income Ratio (DTI) with MoM fluctuations

Good Loan vs Bad Loan KPIs for performance comparison.

### 2. Overview Dashboard
**Visual analytics including:**
- Monthly Trends by Issue Date (Line Chart)
- Regional Analysis by State (Filled Map)
- Loan Term Analysis (Donut Chart)
- Employee Length Analysis (Bar Chart)
- Loan Purpose Breakdown (Bar Chart)
- Home Ownership Analysis (Tree Map)

**Displays metrics:** Total Loan Applications, Total Funded Amount, and Total Amount Received.

### 3. Details Dashboard
Comprehensive loan status grid view providing detailed insights into loan portfolio, borrower profiles, and performance metrics.

## 🛠️ Technologies Used

- **PowerBI Desktop** - Data visualization and dashboard creation
- **MySQL** - Database management
- **DAX** - Data Analysis Expressions for calculations

### 🚀 Setup Instructions

1. **Database Setup**
   - Install MySQL
   - Import the database schema from `database/sample_schema.sql`

2. **PowerBI Connection**
   - Open `Bank_Loan_Analysis.pbix`
   - Update MySQL connection credentials
   - Refresh data source

## 📈 Key Features

- Real-time MySQL data integration
- Month-over-Month (MoM) trend analysis
- Interactive filtering and drill-down capabilities
- Geographic loan distribution mapping
- Loan performance segmentation
